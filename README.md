# SeemaDrishti UI prototype

Reference-based document screening interface with overview, screening, officer review, review queue, case history, and reports. Fictional sample data only; no AI processing or live database connections.

Open `dist/index.html` in a browser or serve `dist/` using any static web server. Navigation and review actions work entirely in the browser. Demo actions reset on reload.

The document specimen and evidence imagery are displayed from the user-provided design references. Inter is loaded from Google Fonts when available, with a local system-font fallback.
